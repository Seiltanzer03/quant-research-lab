# Данные для публичной сборки

По умолчанию здесь нет реальных котировок. Если нет импортированных датасетов, сборка создаёт явно отмеченную синтетическую DEMO-историю.

Для публикации разрешённой истории добавь два файла: `gold.csv` и `gold.profile.json`.
Пример профиля: [configs/xauusd.profile.example.json](../configs/xauusd.profile.example.json).
Укажи настоящий `PROVIDER:SYMBOL`, лицензию, календарь и `publish_allowed: true` **только когда право публичного размещения подтверждено**.

CSV в этой папке и состояние в ветке `lab-state` публичны. Для закрытых данных используй локальный импорт в `data/`, который исключён из Git.

GitHub Pages не принимает загрузки в репозиторий: предпросмотр CSV работает в браузере; сохранение выполняется локальным API либо через обычный коммит в GitHub.
