# Контракт данных

CSV: UTF-8, заголовки `time,open,high,low,close[,volume]`, регистр несущественен. Дополнительные колонки индикаторов игнорируются. Имена можно явно сопоставить через `columns` в профиле: `{ "time": "Date", "open": "Open", ... }`.

`time` — время **открытия** свечи: Unix seconds (`timestamp_unit=s`), Unix milliseconds (`ms`) либо ISO 8601. Для naive timestamp обязателен правильный `timestamp_timezone`; неоднозначное/nonexistent локальное время DST отклоняется. Для смешанных offset надёжнее преобразовать файл к UTC. Все внутренние метки — UTC. MVP использует фиксированную UTC-сетку M15/H1/H4; другие broker anchors пока не поддерживаются.

В профиле фиксируются canonical id, точный source/symbol, класс актива, timeframe, timezone, tick/precision, тип объёма, execution id, лицензия и календарь. Фьючерс требует roll policy; связь с CFD/spot не выводится автоматически.

Правила:

- OHLC конечны и положительны; High ≥ Open/Close/Low, Low ≤ Open/Close/High.
- Volume nullable; отсутствующий объём остаётся null/NaN внутри численной таблицы, а не превращается в рыночный ноль. В JSON NaN запрещён.
- Финализация: bar_close = bar_open + source timeframe; строки с bar_close после времени импорта исключаются из clean. Raw сохраняет оригинал целиком.
- Идентичные дубли удаляются; конфликт цены/объёма на одном source timestamp приводит к отклонению. Коррекция требует нового явно версионированного профиля/source.
- Import id = SHA-256 от raw hash + профиля. Snapshot hash включает профиль и нормализованную историю без времени получения.
- Raw хранится до проверки. Версии Parquet не перезаписываются. SQLite указатель latest может измениться; исходные snapshots сохраняются.
- M15/H1/H4 выдаются только из полного количества закрытых баров с правильными первым/последним timestamp и принадлежностью календарю. Неполные окна пропускаются, не заполняются.

Calendar: IANA timezone; `weekdays` 0=понедельник…6=воскресенье; open/close в минутах местного дня, 1440=конец дня; overnight поддерживается. `closed_dates` закрывает локальную дату целиком. `overrides` задаёт специальные часы для конкретной локальной даты; для overnight-исключений явно настрой обе затронутые даты. DST определяется переходом UTC → IANA local time.

Календарь не загружается автоматически у брокера. `verified=false` или неподтверждённая лицензия даёт HISTORY_INCOMPLETE. Полнота 100% относится только к диапазону от первой до последней загруженной свечи. Она не доказывает многолетнюю полноту истории.

CSV-история становится доступна системе в момент реального импорта. В исторической симуляции отдельно используется гипотеза доступности завершённого бара на его close; такая симуляция никогда не считается live-issued доказательством.
