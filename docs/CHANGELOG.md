# Изменения

## 0.2.0 · 19.11.2026

Личный кабинет в браузере: Worker range/scenario engine, IndexedDB raw/sources/experiments/paper/outcomes, реальные запуск/отмена/импорт/backup/restore, прямой коннектор с честными ошибками доступа, отсутствие демо fallback. Modules/Session-заглушки удалены. Pages не хранит чужие котировки. Параметры и правила v2 отделены от Python v1.

## 0.1.0 · 19.11.2026

GitHub-first pilot: CSV/raw/QA/Parquet/DuckDB/SQLite; complete UTC bars; fixed B0/B1 research; Russian React dashboard; explicit DEMO and NO_FORECAST; Actions state persistence and Pages workflows; local API and launch scripts. Webhook and live trading are not implemented.

## 0.3.0 · 19.11.2026

Готовая открытая история XAUUSD/Nasdaq 100 M5 2024–2025, SHA-256/атрибуция, автоматическая загрузка без ключей/регистрации. Настоящие reference-отчёты считаются при сборке, изменение параметров — Worker в браузере. Replay сохраняет исходное M5-разрешение и ambiguity bounds. Протокол v3/schema2.1; experiment id учитывает код. OANDA не подключён. Архив не выдаётся за live-feed.

## 0.3.1 · 19.11.2026

Годы во всех датах, подпись UTC для исследовательского периода. Элементы будущего прогноза показываются только при подходящем свежем M1-источнике; архив показывает число исходных свечей. Подтверждены на опубликованном сайте автоматическая загрузка, Worker rerun, отдельные experiments, Nasdaq H1 и настоящий M5 TP/SL JSON.
