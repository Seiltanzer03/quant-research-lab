# Квант лаб · v0.2

Личный исследовательский кабинет: **полный расчёт в браузере**, реальные OHLC, baseline-диапазоны и TP/SL replay. Демо больше не используется при открытии сайта.

**[Открыть приложение](https://seiltanzer03.github.io/quant-research-lab/)**

## Как работать

1. Выбери XAU/USD либо US100 CFD, даты и нажми **Загрузить котировки**. Коннектор обращается напрямую к публичному chart API Dukascopy™; цены не копируются в публичный репозиторий. Максимальный период — 366 дней. При HTTP429/пустом ответе/отказе приложение показывает реальную ошибку и сохраняет прежнюю работу.
2. Либо открой **Данные и контроль → Импортировать CSV и выполнить исследование**. Выбери файл, укажи точный `PROVIDER:SYMBOL`, класс актива, timeframe и формат времени. Кнопка **Импортировать и посчитать** действительно сохраняет свечи и выполняет исследование на Pages; Python, сервер и коммит не требуются.
3. В **Исследованиях** меняй окно обучения и минимум наблюдений, запускай расчёт на выбранном периоде, сравнивай B0/B1. Все завершённые запуски записываются, одинаковый snapshot/параметры не создают дублей.
4. В **Мой TP / SL** задай Entry, TP, SL и издержки. На M1-истории рассчитываются наблюдаемые частоты касаний, первый TP/SL, неоднозначные M1, time exit, средний R и bootstrap-интервал. Это исторический replay заданных правил, не доказанная вероятность будущей сделки.
5. **Сохранить работу** создаёт резервную копию данных, отчётов и журналов. Импорт копии доступен в разделе данных.

Котировки, исходные CSV и результаты хранятся в IndexedDB **этого браузера**, не отправляются в GitHub или разработчику. Другой браузер/устройство требует восстановления копии. Очистка данных сайта удаляет локальную базу — сохраняй резервные копии.

## Источники и доступность

| Рынок | Точный источник | Что это |
|---|---|---|
| XAUUSD | `DUKASCOPY:XAU/USD` | Spot gold этого провайдера, Bid |
| NAS100 | `DUKASCOPY:USATECH.IDX/USD` | US100 CFD этого провайдера, Bid |
| CSV | Указанный пользователем `PROVIDER:SYMBOL` | Собственные котировки из TradingView/брокера |

Котировка Dukascopy не подменяет брокерскую. NQ, GC, NDX и CFD автоматически не отождествляются. Недельные часы Dukascopy заданы по [официальным trading sessions](https://wiki.dukascopy.com/en/manuals/jforex4-desktop/trading-sessions); праздники требуют отдельной проверки. CSV-календарь не подтверждён: исследуются полные наблюдаемые UTC-окна, но проценты полноты по биржевым сессиям не заявляются. GC_F и NQ_F импортируются как самостоятельные фьючерсные серии, не как spot/CFD-замена.

В проверке из исполнительной среды и GitHub Actions endpoint Dukascopy вернул **HTTP429**. Коннектор останавливается при отказе, не меняет IP/заголовки для обхода и не подставляет синтетическую историю. В проверке опубликованного сайта из облачного браузера источник также не ответил. Автоматическая онлайн-загрузка не подтверждена; это текущий открытый блокер, а не рабочий live-feed. Независимый от API полный CSV-процесс реализован на сайте.

Источник предусматривает CORS/JSONP. JSONP исполняется в sandboxed iframe без доступа к IndexedDB основного приложения. API proxy и токенов в JavaScript нет. Использование котировок личное; публичная ретрансляция не реализована.

## Что считает ядро

- **B0:** эмпирические сезонные квантили прошлых High/Low excursions, pooled fallback при малой группе.
- **B1:** те же excursions в масштабе EWMA-волатильности, известной до целевого окна.
- Полные M15/H1/H4; joint coverage 50/80/90/95%, width, envelope score, pinball, режимы/часы/месяцы, парный bootstrap по UTC-дням.
- Протокол v2: 60/20/20, два фиксированных кандидата, seed42, 400 bootstrap-повторов. Версии не смешиваются с Python baseline v1.
- Исторический as_of отделён от настоящего времени расчёта. Просмотренный test не считается навсегда нетронутым holdout.

**Следующая свеча:** при свежей M1 (≤3 минут), проверенном недельном календаре и отсутствии критических gaps можно рассчитать диапазон следующего полного UTC-бара. Текущее окно не объявляется заранее предсказанным. Lead до начала окна учтён в обучающих anchor. Запись до события не перезаписывается; после полной истории окна сохраняется отдельный outcome.

Это личный paper-journal с часами браузера, не независимое доказательство внешней публикации. Методы не получают `VALIDATED` или доказанную прибыльность. Устаревшие котировки, перерывы и пропуски могут правильно заблокировать конкретный прогноз.

Автообновление работает **пока открыта вкладка**, по опции раз в минуту; после ошибки останавливается. Для 24/7 нужен постоянный worker. Actions проверяет код и публикует приложение; сборка демо каждые 6 часов отключена.

## Технологии и запуск

React/TypeScript + Web Workers + IndexedDB + Lightweight Charts. Python/FastAPI/DuckDB/Parquet/SQLite остаются дополнительным локальным инструментом CSV-исследований v1. Сайт не требует их установки.

```bash
cd frontend
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173. Не используй file://: worker/IndexedDB требуют нормальный origin.

```bash
ruff check backend scripts
pytest -q
npm --prefix frontend test
npm --prefix frontend run build
```

Подробности: [browser protocol v2](docs/BROWSER_PROTOCOL_V2.md), [приёмка](docs/ACCEPTANCE.md). Полное исходное ТЗ — [SPEC_v1](docs/SPEC_v1.md); все его будущие модули не считаются выполненными. Неработающие Modules/Session-кнопки удалены.
