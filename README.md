## Что уже можно делать

- Смотреть реальные свечи M15/H1/H4, исторические диапазоны 50/80/90/95% и фактические исходы.
- Выбирать даты, менять lookback/minimum sample и запускать новое исследование прямо на Pages. Расчёт выполняет Web Worker; завершённые эксперименты сохраняются.
- Сравнивать фиксированные B0/B1 на одинаковых test timestamps: joint High/Low coverage, ширина, envelope score, pinball, калибровка по режимам/часам/месяцам и парный bootstrap по дням.
- В «Мой TP / SL» задавать Entry, TP, SL и издержки: реальные исторические пути, первый TP/SL, time exit, неоднозначные касания, нижняя/верхняя граница среднего R и bootstrap CI. На готовой истории используется M5. Порядок внутри M5 не выдумывается; M1 можно импортировать отдельно.
- Импортировать собственный CSV, выполнять полный расчёт, сохранять и восстанавливать рабочую базу. CSV остаётся в браузере и в GitHub не отправляется.
- Скачать JSON конкретного исследования, сценария, исторического журнала и всех своих экспериментов.

При первом открытии используются проверенные по SHA-256 файлы архива и отчёт, реально рассчитанный в сборке. Любое изменение параметров/периода пересчитывается в браузере. Неработающие Modules/Session-кнопки удалены.

## Правила исследования

Протокол **v3**, модель `browser_ranges_v3`, схема отчёта 2.1. B0 — долевые excursions; B1 — excursions в масштабе известной ранее EWMA-волатильности. Хронологические 60/20/20, два фиксированных кандидата, day-block bootstrap seed42/400. Параметры, профиль, snapshot hash, Git SHA и результаты связаны с экспериментом. Новая версия кода не перезаписывает старый результат.

M5 не превращается в выдуманные M1. Полные агрегированные окна требуют все исходные свечи. UTC gaps не заполняются. Для CSV/архива календарь не подтверждён: пропущенные слоты включают выходные и перерывы, процент биржевой полноты не заявляется. Предсказанный диапазон не равен вероятности прибыльной сделки.

Просмотренный test не становится навсегда нетронутым holdout. Метрики диапазонов и TP/SL replay не являются доказательством прибыльности. Самостоятельного непрерывного поиска новых моделей в этой версии нет.

Личный forward-journal реализован отдельно: только свежая закрытая M1, подтверждённая недельная сессия, gap/late gates, реальное время записи. **Готовый M5-архив не может выдать live-прогноз**. Исторические симуляции не получают статус заранее опубликованных.

## Хранение и запуск

Открытая лицензированная reference-история включена в приложение. Личные CSV, отчёты, эксперименты и journal — IndexedDB текущего браузера. Для другого устройства используй «Сохранить работу» / «Восстановить копию». Очистка данных сайта удаляет личную базу.

React/TypeScript, Web Worker, IndexedDB, Lightweight Charts. Python/FastAPI/DuckDB/Parquet/SQLite остаются дополнительным локальным CSV-инструментом v1. GitHub Actions проверяет код, считает настоящие reference-отчёты и публикует Pages. Непрерывный процесс 24/7 не заявлен.

```bash
cd frontend
npm ci
npm run dev
```

Проверки:

```bash
ruff check backend scripts
pytest -q
npm --prefix frontend test
npm --prefix frontend run build
```
